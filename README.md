# Red Lanterns

Persönliches, KI-unterstützt entwickeltes Browser-Spielprojekt von Joel Mazurek.

Der lokale Entwicklungsstand trägt im Spiel noch den Arbeitstitel **Lantern Wars**. Dieses Repository enthält die lokal vorliegende Fassung vom **31. Oktober 2026, 02:03 Uhr**. Es ist ein experimenteller Prototyp mit einer umfangreichen HTML-/JavaScript-Datei.

## Starten

`index.html` herunterladen und im Browser öffnen. Alternativ im Projektordner einen lokalen Webserver starten:

```bash
python3 -m http.server 8080
```

Danach `http://127.0.0.1:8080` öffnen. Für externe Schriftarten ist Internet nötig; eingebettete Inhalte und Spielcode liegen in der HTML-Datei.

## Einblick

- Browser-Spiel mit Canvas-Darstellung und JavaScript.
- Spielwelt mit Kampagnen- und Sandbox-Modus.
- Menüs auf Deutsch und Englisch.
- Iterative Arbeit an Spielideen, Abläufen und Darstellung.

## Entwicklungsweise

Ich nutze KI-Unterstützung für die Entwicklung und arbeite iterativ an Ideen, Spielabläufen und Anpassungen. Das Projekt zeigt mein Interesse an Game Design und am Experimentieren mit Software. Es ist kein Beleg für fortgeschrittene, vollständig eigenständig geschriebene Engine-Entwicklung.

Der Stand wurde vor Veröffentlichung auf JavaScript-Syntax und offensichtliche Zugangsdaten geprüft. Ein vollständiger Spieltest ist damit nicht abgedeckt. Bekannte Probleme und weitere Änderungen werden nach und nach dokumentiert.

Die im Spiel enthaltenen Sound-Credits und Quellenangaben bleiben in `index.html` erhalten.
